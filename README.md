# Secure Coding Agent

This repository contains the Secure Coding Agent project structure for the Nebius x NVIDIA Global AI Hackathon.

## Project Overview
The system is organized into the following main areas:

- `apps/` – application services and execution layers
- `packages/` – reusable logic modules and security components
- `policies/` – governance and policy definitions
- `tests/` – unit, integration, and security validation suites
- `docs/` – project documentation and process notes
- `infra/` – infrastructure and deployment configuration
- `frontend/` – user-facing interface
- `evaluation/` – evaluation and benchmarking assets

## Ownership
Each subfolder is assigned to a responsible team or contributor for maintenance and delivery.
